# V0.1 milestone：函数与原始汇编浏览

本轮人工验收反馈已落实，V0.1 整理为本次 GitHub 提交基线。[V0.2 单函数候选展示](../v0.2/PLAN.md)已确认计划，尚未实现。使用流程见 [USAGE.md](USAGE.md)，Agent 入口见 [SKILL.md](../../../SKILL.md)。

## 交付范围

用户通过 Skill 指定 ARM64 二进制或样本目录，Agent 先导出分析结果，再打开 Web，供人工查看函数、地址、行数与完整原始汇编。

| 功能 | V0.1 行为 |
| --- | --- |
| 分析导出 | 独立入口调用 Rizin `aaa`，将函数与完整汇编写入 SQLite |
| 外部 workspace | 默认位于会话工作目录，拒绝写入 LightRE 工具仓库和样本 Git 仓库；相同 SHA256 复用原目录 |
| 结果复用 | 身份、结果格式、导出流程和 Rizin 版本匹配时复用完整结果；显式 `--force` 可重新导出 |
| 保存一致性 | 函数和汇编在同一事务内替换，移除旧记录；导出失败回滚并保留上一份完整结果 |
| 只读浏览 | Web 从保存的 SQLite 读取，不调用分析工具，不要求原始二进制存在 |
| 函数列表 | 显示 RVA、NAME、LINES；按名称或十六进制 RVA 搜索，按行数或 RVA 排序，默认按行数降序 |
| 汇编浏览 | 显示 RVA、机器码和指令；每页最多 200 条，向下滚动自动追加，读取失败可重试 |
| 紧凑布局 | 顶栏 44px、页脚 22px、正常加载进度栏 28px；压缩标题、搜索、表头和列表留白 |
| 左栏调宽 | 默认 240px，范围 220–400px；窄视口进一步限制最大宽度。支持拖动、方向键微调、双击恢复默认，浏览器保存宽度 |
| 列布局 | 桌面三列按 1:1.4:1 分配可用宽度，并保留 RVA、LINES 的最小列宽；LINES 表头与数字居中，长名称省略并可悬停查看 |
| 主题 | 图标切换浅色/深色，浏览器保存偏好 |
| 更换目标 | 每个 Web 进程固定读取一份 SO 结果；换目标由 Skill 重启服务，页面不提供工作区切换 |

## 两个样本的现场记录

以下为本地 `/work2` 环境的实际结果，分析产物不随工具仓库提交。其他环境按实际输入和会话目录生成路径。

| 样本 | 输入 | SO 分析目录 | 已识别函数 |
| --- | --- | --- | --- |
| dg | `/work2/dg-samples/dC6BDAE/libdC6BDAE49562F.so` | `/work2/dC6BDAE-analysis/dC6BDAE-d65f` | 412 |
| minilua | `/work2/LightRE/samples/minilua/deliverable/minilua` | `/work2/minilua-analysis/deliverable-0432` | 236 |

- dg 保存 74,083 条汇编记录；最大函数 `0x1c07c` 为 47,180 行，短函数 `0x76c8` 为两行。
- minilua 的参考函数 `luaH_get`、`luaH_set` 分别为 526、138 条指令，前期开发检查已与配套参考机器码核对。
- 两个样本均已通过 Skill 流程打开，先后在 `http://localhost:8000` 浏览；该地址是本地服务地址，容器外访问需要端口映射。

人工启动快捷指令：[dg_start.md](../../../tests/dg_start.md)、[minilua_start.md](../../../tests/minilua_start.md)。它们只指定样本，用于减少重复输入，不附加自动验收任务。

## 验证方式

以人工审阅代码和查看界面为主。本轮按两份启动指令打开样本，并根据人工反馈完成界面收尾；启动时只确认首页可访问、函数列表身份与目标一致。

开发测试仅保留 [test_workspace.py](../../../tests/test_workspace.py) 的 7 项快速测试，最近一次运行全部通过，约 0.06 秒。覆盖工作区命名与复用、数据库只读、缺失目录不创建、导出替换与失败回滚、RVA 分页及无效 ARM64 指令槽位。使用临时文件与模拟数据，不启动 Web、Rizin 或浏览器。

前期执行过真实结果、HTTP 和浏览器检查；对应全量测试脚本及 Playwright 依赖已删除。历史检查不作为每次启动的前置条件，也不代替人工验收。

## 当前限制与前期修复

- 当前只支持 ARM64 ELF 的静态函数与汇编浏览；函数数量和边界是 Rizin 的识别结果，不保证完整或正确。
- 没有 CFG、基本块界面、反编译候选、LLM 自动还原、unidbg、Evidence 库、Web 评论或自动迭代；这些仍属于后续方案。
- 新结果导出后手动刷新页面；Web 不自动运行分析或迁移旧结果。
- 本地 minilua 的显示名称沿用输入父目录 `deliverable`，workspace 名称为 `minilua-analysis`。

前期 dg 曾错误识别为 394 个函数，原因是项目目录改名后非 portable Rizin 仍使用旧编译前缀，且分析命令不一致。已重建 portable Rizin 并统一 `aaa`；当前为 412 个函数，`0x1c07c` 为 47,180 行、188,720 字节、6,827 个工具识别基本块。基本块数量仅用于核对，不进入页面。
