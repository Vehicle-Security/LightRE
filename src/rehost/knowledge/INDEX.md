# Rehost 知识库

跨 SO、跨轮次共享的 unidbg rehost 经验。本文件是使用说明；条目保存在同目录的主题文件中。

## 何时使用

- 调查或补环境遇到不确定点时，先查对应主题文件，避免重复踩坑。
- 本轮通过真实运行得到的新结论（失败原因、可用配方、SO 模式）在结束前追加到对应主题文件。
- 只记录有真实运行或检查证据的经验；猜测、未验证的想法写明"未验证"。
- 引用来源：写明来自哪个 SO（SO 名或哈希前缀）和哪轮 Run/检查记录。

## 条目格式

每个主题文件用 H2 作为一条独立经验，格式：

```markdown
## <一句话标题>

- 症状：实际遇到的现象/报错（含关键日志行）
- 原因：经调查确认的根因
- 解法：可复用的具体做法（代码片段或步骤）
- 来源：<SO 名> <轮次/Run 路径>；<日期>
```

## 约束

- 追加经验，不重写他人条目；发现旧条目有误时在其下方补"更正"条目并注明依据。
- 不把某 SO 的地址、哈希、特定环境值当作通用结论。
- 本目录不是任务状态；每轮结论仍以 HARNESS.md 和 Run 记录为准。
