# 从汇编恢复 C 候选

以任务提供的全部已保存汇编为起点，按基本块追踪控制、数据和调用关系。保留调用约定、访问宽度、内存写入、异常与清理路径；旧知识是待核对线索，不能替代机器证据。

不要求先完成 SSA 或证明全部路径。大型、混淆函数可保留状态机、goto、位运算和低层类型；不要为了恢复业务名称而推测行为，也不要仅因复杂就放弃有依据的候选。

任务已内嵌全部已保存指令时，直接使用正文，不重新分页读取同一份汇编。只为具体疑点取证：例如某个操作数对应的字节、遗漏的分支目标、访问宽度或间接调用签名。保存的 ranges 不是函数完整性的证明。

需要核对 ELF 地址、保存边界或缺失块时，读取 [ELF_ADDRESSES.md](references/ELF_ADDRESSES.md)，再用任务提供的只读工具查询。仅汇编任务不能读取 Ghidra 伪代码、参考导出或项目。

逐个区分已确认机器行为、推断和未覆盖路径。知识中的旧名称或结论与本轮代码不一致时，整理为完整当前分析，保留有效证据地址、假设和未知项，不追加逐轮日志。

不能把整段汇编包成内联汇编冒充 C，也不能用空函数、固定返回、待实现 helper 或省略号填补缺失行为。确实不能形成有依据的候选时，返回 null 并说明具体缺口；所有结果仍未经编译或执行验证。
