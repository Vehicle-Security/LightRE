# ELF 地址与缺失块核对

LightRE 的函数目录、范围和汇编地址列使用 RVA。任务内嵌汇编的直接分支／调用目标已经转换为 RVA；其他操作数仍可能使用保存的 image_base 地址体系。原始操作数和机器码保存在逐函数 `.asm` 快照中。

核对原 ELF 前先用 readelf 查看 ELF 段的地址和文件偏移。objdump 使用原 ELF 的地址，不能直接套用 Ghidra 或汇编快照的加载基址；根据对应 PT_LOAD 段解释虚拟地址与文件偏移。

遇到跳转落在保存 ranges 外、函数入口位于内部块或相邻字节疑似被误标为数据时，检查相关范围和实际机器码；保留原 RVA 与证据，不擅自修改目录、调用约定或扩大本批发布范围。

只补查有具体疑点的邻近块。说明补查覆盖了什么、还有哪些范围未知，不把“全部已保存指令”称为“已证明完整函数”。
