# 核对已有候选

先使用任务内嵌的当前源码、参考及知识；未提供时，按任务给出的 API 读取指定 RVA 的候选和函数知识。源码文件可能包含多个函数，只分析本批身份对应的正文。

把参考伪代码作为理解线索，以实际机器行为核对内存副作用、调用约定、间接跳转和可疑分支。已有完整初稿时允许保守保留混淆结构和有警告的路径，说明其局限，不为整洁删去未理解的行为。producer=ghidra 只代表初稿，不代表已完成 LLM 核对。

遇到地址换算、halt_baddata、丢失寄存器副作用、缺失路径或历史边界变更时，按需读取 [REFERENCE_CHECKS.md](references/REFERENCE_CHECKS.md)，只调查相关证据。参考很长时使用任务提供的逐函数 API 获取全文，不截断后冒充完整输入。

评论任务只完成该条建议涉及的调查，不借机重新开展整轮逆向。没有可用初稿而需要从汇编形成候选时，可选择目录中的汇编恢复方法，但仍遵守本批输入限制。

保留有依据的类型、业务名称、外部调用及副作用；不能编造调用结果、固定返回或缺失实现。同步整理完整当前知识，保留事实、证据、有效假设及未知项，不将未经执行验证的候选称为语义等价。
