# 参考伪代码与原始证据

Ghidra 的 FUN_/DAT_ 名称包含 VA，需减去该参考记录的 image_base 才能与本 SO 的 RVA 对齐。原 ELF 的 objdump 地址体系不一定与 Ghidra 相同，先用 readelf 检查段映射后换算。

halt_baddata 或 Ghidra 不支持某条指令，不代表原逻辑不存在。使用 objdump 核对原 ELF 的实际字节与邻近指令，尤其留意错误反编译是否省略寄存器、内存或调用副作用。

上下文恢复、SME/GCS 等依赖显式机器状态的底层 helper，可在说明依据后以局部内联汇编保留 ABI；必须保留实际编码和条件。此例外不允许将核心 VM 解释器机械复制为汇编冒充可读 C。

函数目录、范围和参考分组可能有缺口；历史边界变化中的旧候选只能作为线索。依据当前范围与原始证据判断，不擅自改变 RVA 身份或调用约定，不把 Ghidra 分组当作原始源码模块。
