# 汇编、地址与缺失路径

函数目录、ranges 和汇编地址列使用 RVA。内嵌汇编的直接分支/调用目标已转换为 RVA；其他操作数仍可能使用保存的 image_base。原始操作数、机器码和 ranges 保存在逐函数 .asm 快照。Ghidra 的 FUN_/DAT_ 名称含 VA，先减去对应参考记录的 image_base 才能与本 SO 的 RVA 对齐。

核对原 ELF 前用 readelf 查看 PT_LOAD 段的地址和文件偏移。objdump 使用原 ELF 的地址，不能直接套用 Ghidra 或快照加载基址，须按段映射换算。工具位置与 Python 路径由任务提供；用 reader.assembly(rva, offset=..., limit=200) 按 next_offset 读取尚未提供的汇编，不能将首尾片段当作完整函数。

按基本块追踪控制、数据和调用关系，保留调用约定、访问宽度、内存写入、异常与清理路径。不要求先完成 SSA 或证明全部路径，大型函数允许保留状态机、goto、位运算和低层类型。

halt_baddata 或 Ghidra 不支持指令不代表原逻辑不存在。核对原 ELF 的实际字节及邻近指令，尤其检查反编译是否遗漏寄存器、内存或调用副作用。跳转落在 ranges 外、入口位于内部块或相邻字节疑似误标为数据时，只补查有依据的相关块；保留原 RVA，不擅自修改目录、调用约定或扩大发布范围。

上下文恢复、SME/GCS 等依赖显式机器状态的底层 helper，可在说明依据后用局部内联汇编保留 ABI，须保留实际编码与条件；不能将核心函数整段包成内联汇编冒充可读 C。

未覆盖块、间接调用签名和推断必须明确说明。保存范围及“全部已保存指令”不是函数完整性的证明，Ghidra 模块分组和历史旧候选也只是线索。没有初稿且确实无法形成有依据的候选时返回 null，记录具体缺口与下一步；不删除未知副作用或填充缺失实现。
